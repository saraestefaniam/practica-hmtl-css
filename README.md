# **Portafolio web Sara Morales**
Esta es mi práctica de portafolio personal, donde presento mis habilidades como creadora de contenido digital.

## **Descripción del proyecto**
El proyecto fue realizado con **HTML** y **CSS**. Además, está optimizado bajo el enfoque **Mobile-First**.

### **Tecnologías utilizadas**
- **HTML**: estructura general del sitio.
- **CSS**: estilos y diseño del sitio.
- **Flexbox** y **Grid**: layout y organización del contenido en el sitio.
- **Responsividad Mobile-First**: prioridad al diseño en dispositivos móviles y luego escalabilidad hacia pantallas de escritorio.

### **Características principales**
- **Header** con logo y menú.
- Sección de **Podcast** con video.
- Sección de **Portfolio** con proyectos organizados con grid.
- Sección de **Contacto** con formulario.
- **Footer** con información de contacto y enlaces a redes sociales.
- **Menú hamburguesa** hecho con CSS y que se adapta a dispositivos móviles.
- **Barra de progreso** que representan mis habilidades.
